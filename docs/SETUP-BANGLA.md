# STREAM SETUP CENTER - ব্যবহারিকা (Bangla Guide)

হ্যালো! আপনার অটোমেটেড উইন্ডোজ সফটওয়্যার ইন্সটলার সিস্টেম তৈরি হয়ে গেছে। নিচে ধাপে ধাপে নিয়মগুলো দেওয়া হলো, যেন আপনি খুব সহজেই এটি ব্যবহার করতে পারেন।

## ১. GitHub রিপোজিটরি তৈরি ও রিলিজ (Release) আপলোড

যেহেতু আপনার কিছু ফাইল অনেক বড় (যেমন ১.৭৭ জিবি), তাই আমরা GitHub Releases ব্যবহার করব। 

**ধাপগুলো:**
১. [GitHub](https://github.com/)-এ গিয়ে লগইন করুন।
২. ডানপাশের ওপরে **"+"** আইকনে ক্লিক করে **"New repository"** সিলেক্ট করুন।
৩. Repository name দিন: `STREAM-SETUP-CENTER`।
৪. Public সিলেক্ট করুন এবং "Create repository" বাটনে ক্লিক করুন।
৫. আপনার পিসির `STREAM-SETUP-CENTER` ফোল্ডারের ফাইলগুলো (install.ps1, apps.json ইত্যাদি) গিটহাবে আপলোড করুন। 

**বড় ফাইল (Installer) আপলোডের নিয়ম:**
১. আপনার রিপোজিটরির ডানদিকে **"Releases"** অপশনে ক্লিক করুন (অথবা Create a new release-এ ক্লিক করুন)।
২. Choose a tag-এ লিখুন `v1.0` এবং Create new tag-এ ক্লিক করুন।
৩. Title-এ লিখুন `Initial Software Installers`।
৪. নিচে **"Attach binaries by dropping them here or selecting them"** বক্সে আপনার সবগুলো `.exe` ফাইল (Chrome, BlueStacks, ইত্যাদি) ড্র্যাগ অ্যান্ড ড্রপ করুন। (সর্বোচ্চ ২ জিবি প্রতি ফাইল সাপোর্ট করে, তাই আপনার ১.৭৭ জিবির ফাইলটি অনায়াসে আপলোড হবে)।
৫. আপলোড শেষ হলে **"Publish release"**-এ ক্লিক করুন।
৬. এখন প্রতিটি ফাইলের নামের ওপর রাইট ক্লিক করে **"Copy link address"** করুন। এটাই আপনার Download URL।

## ২. apps.json আপডেট করা (SHA-256 এবং URL)

আপনার `apps.json` ফাইলে আমি আপনার দেওয়া ৩৯টি সফটওয়্যারের নাম এবং সিরিয়াল দিয়ে দিয়েছি। কিন্তু সেগুলোতে `"sha256": "PLACEHOLDER"` এবং `"url": "https://example.com/..."` দেওয়া আছে। এগুলো আপনাকে আপডেট করতে হবে।

**সহজে SHA-256 বের করার নিয়ম:**
আপনার সুবিধার জন্য আমি একটি স্ক্রিপ্ট তৈরি করেছি `scripts/generate-config.ps1`। 
PowerShell খুলে নিচের কমান্ডটি চালান (যেখানে আপনার সব সফটওয়্যার আছে সেই ফোল্ডারের পাথ দিন):

```powershell
.\scripts\generate-config.ps1 -InstallerFolder "C:\Path\To\Your\Installers"
```
এটি স্বয়ংক্রিয়ভাবে সবগুলোর সাইজ এবং SHA-256 বের করে একটি নতুন `generated_apps.json` তৈরি করবে। সেখান থেকে হ্যাশ কপি করে আপনার মেইন `apps.json`-এ বসিয়ে দিন।
আর URL-এর ঘরে আপনার GitHub Release থেকে কপি করা লিংকটি বসান।

## ৩. ফাইল রান করার নিয়ম (One-Command)

সবকিছু গিটহাবে আপলোড এবং সেটআপ হয়ে গেলে, আপনি যেকোনো নতুন উইন্ডোজ পিসিতে গিয়ে শুধু PowerShell (অ্যাডমিন হিসেবে খুললে ভালো) খুলে নিচের কমান্ডটি চালাবেন:

```powershell
irm https://raw.githubusercontent.com/আপনার-ইউজারনেম/STREAM-SETUP-CENTER/main/install.ps1 | iex
```

*(আপনার-ইউজারনেম এর জায়গায় আপনার গিটহাবের ইউজারনেম বসাবেন)*

এরপর আর কিছু করতে হবে না। স্ক্রিপ্ট নিজে থেকেই:
- ডাউনলোড ফোল্ডার তৈরি করবে।
- একটার পর একটা সফটওয়্যার ডাউনলোড করবে।
- হ্যাশ ভেরিফাই করবে।
- সাইলেন্ট ইন্সটল করবে।
- শেষে একটি সুন্দর রিপোর্ট দেখাবে।

## কিছু জরুরি কথা (Security Rules):
- আমাদের স্ক্রিপ্ট Windows Defender বা UAC ডিজ্যাবল করে না, যা আপনার সিস্টেমকে নিরাপদ রাখে।
- সাইলেন্ট ইন্সটলের আর্গুমেন্ট (যেমন `/S` বা `/quiet`) সফটওয়্যারভেদে ভিন্ন হয়। আমি স্ট্যান্ডার্ড আর্গুমেন্ট দিয়েছি, যদি কোনোটা কাজ না করে তবে সেটির আর্গুমেন্ট ফাঁকা (`""`) করে দিন, তাহলে সেটা সাধারণ নিয়মে (ম্যানুয়ালি নেক্সট করে) ইন্সটল হবে।
- .NET, Visual C++ এবং DirectX-এর সিরিয়াল আগে রাখা হয়েছে যেন অন্য সফটওয়্যারগুলোতে কোনো এরর না আসে।
